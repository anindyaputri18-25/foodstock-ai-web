# FoodStock AI Forecasting — Revisi Poin 1–18

Aplikasi prototipe Next.js + React + TypeScript + Zustand. Panduan lengkap instalasi, daftar route, cara mencoba fitur, dan batasan prototipe ada pada `PANDUAN_LENGKAP_POIN_1-18.md`.

## Menjalankan lokal
```bash
npm install
npm run dev
```
Buka http://localhost:3000.

> Penting: aplikasi saat ini masih prototipe frontend dengan penyimpanan localStorage dan forecast simulasi. Baca bagian batasan pada panduan sebelum deployment produksi.
